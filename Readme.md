# Vidma - Video Downloader for Android

A clean, fast video downloader for Android built with Kotlin.

## Features

- Download videos from YouTube, TikTok, Instagram, Twitter, Facebook
- Choose quality (Best, 1080p, 720p, 480p)
- Download as MP4 video or MP3 audio
- Background downloading
- Free and open source

## Download

Get the latest APK from [Releases](https://github.com/YOUR_USERNAME/Vidma/releases)

## Build from Source

1. Clone the repo
2. Open in Android Studio
3. Build and run
